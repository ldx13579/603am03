# 智能立体车库停车引导与计费系统

嵌入式项目：模拟3层升降横移式立体车库，实现智能停车引导、路径规划、阻塞检测与计费功能。

## 系统架构

```
┌─────────┐    ┌──────────────┐    ┌─────────────┐
│  CLI    │───>│ State Machine│───>│ Path Planner│
│ (用户界面)│    │  (状态机)     │    │  (路径规划)  │
└─────────┘    └──────────────┘    └─────────────┘
                      │                    │
               ┌──────┴──────┐      ┌──────┴──────┐
               │   Garage    │      │   Billing   │
               │  (车库模型)  │      │   (计费)    │
               └─────────────┘      └─────────────┘
                      │
               ┌──────┴──────┐
               │   Logger    │
               │  (操作日志)  │
               └─────────────┘
```

## 车库布局

3层 x 5车位，升降横移式结构：

```
第3层: [小型] [通用] [通用] [通用] [小型]
第2层: [小型] [通用] [通用] [通用] [小型]
第1层: [小型] [通用] [升降口] [通用] [小型]
```

- 第1层（地面层）：车辆可直接驶入/驶出
- 第2、3层：需通过升降机+横移机构存取
- 第3号位（中间）为升降通道，不停车
- 边缘车位（1号、5号）仅限小型车

## 功能特性

- **智能车位分配**：优先地面层，按距离升降口远近排序
- **状态机控制**：IDLE → PARKING/RETRIEVING → MOVING → IDLE
- **路径规划**：自动生成升降+横移动作序列
- **阻塞检测**：检测路径上的阻碍车辆，自动临时腾挪
- **计费系统**：按分钟计费，前15分钟免费，设有每日上限
- **操作日志**：记录所有存取车、移动、计费操作

## 计费标准

| 车型 | 费率 | 免费时段 | 每日上限 |
|------|------|----------|----------|
| 小型车 | 0.20元/分钟 | 前15分钟 | 60元 |
| 大型车 | 0.35元/分钟 | 前15分钟 | 100元 |

## 编译运行

### Windows (MinGW/gcc)

```bat
build.bat
bin\parking_garage.exe
```

### Linux/macOS

```bash
make
./bin/parking_garage.exe
```

### 手动编译

```bash
gcc -std=c11 -Wall -I./include src/*.c -o parking_garage
```

## 使用说明

启动后进入交互菜单：

1. **存车**：输入车牌号和车辆类型(S/L)，系统自动分配车位并输出动作序列
2. **取车**：输入票号，系统规划取车路径并计算费用
3. **状态**：查看当前车库占用情况
4. **日志**：查看操作历史记录
